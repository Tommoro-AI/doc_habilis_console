# 1.1 설치 파일 다운로드

본인의 운영체제(OS) 환경에 맞는 설치 파일을 선택하여 다운로드하세요.
설치 파일은 
<a href="https://tommoro.ai/download"
   target="_blank"
   rel="noopener noreferrer"
   style="color:#1B4F9C; font-weight:600;">
   다운로드 페이지
</a> 에서 받을 수 있습니다.

![설치 파일 다운로드](./image/1_launcher_download_page.png)


:::tip[참고]
리눅스의 경우 다음의 명령어로 CPU 아키텍처를 확인한 뒤 본인의 환경에 적합한 버전으로 설치해주시면 됩니다.
```bash
uname -m | sed 's/aarch64/arm64/; s/x86_64/amd64/'
```

출력
```bash 
amd64 #AMD 버전 설치
OR
arm64 #ARM 버전 설치 
```
:::

# 1.2 윈도우 설치 방법

윈도우 환경에서는 설치 마법사(MSI)를 통해 간편하게 설치할 수 있습니다.

## Step 1. 런처 설치

1. 다운로드한 설치 파일(`.msi`)을 찾아 더블 클릭하여 실행합니다.
![예시 이미지](./image/win_step1.png)
    
2. 설치 창이 열리면 안내에 따라 [Next] 버튼을 클릭하고, 이어서 <strong> [Install]</strong>을 눌러 설치를 시작합니다.
![예시 이미지](./image/win_step2.png)
![예시 이미지](./image/win_step3.png)

:::tip[참고]
보안 경고 창(SmartScreen)이 나타나면 추가 정보 클릭 후 실행 버튼을 누르세요.
:::

3. 진행바가 모두 채워지면 설치가 완료된 것입니다. <strong> [Finish]</strong> 버튼을 클릭하여 설치 마법사를 닫아주세요.
![예시 이미지](./image/win_step4.png)
    
## Step 2. WSL 설치

1. PowerShell을 관리자 권한으로 실행해주세요.

2. 아래 명령어를 실행해주세요.
```bash
wsl --install
```

## Step 3. 런처 실행

1. 바탕화면에 생성된 '하빌리스 런처' 아이콘을 실행하거나, 윈도우 검색창에서 이름을 검색하여 프로그램을 실행하세요.
![예시 이미지](./image/win_step5.png)

# 1.3 리눅스 설치 방법

리눅스 환경에서는 AppImage 실행 파일을 통해 하빌리스 런처를 실행할 수 있습니다.  
아래 절차에 따라 파일을 다운로드하고 실행하십시오.

---

## Step 1. 다운로드

1. 파일을 다운로드할 디렉토리로 이동합니다.

```bash
cd ~/Downloads
```

2. 최신 릴리스를 다운로드합니다.

    아래 명령어 중 하나를 선택하여 실행하십시오.

**<span style="padding-inline-start:40px;color:#1E90FF;">방법 A</span> — curl 사용**



```bash
#AMD
curl -L -o habilis-launcher.AppImage https://dl.habilis-console.com/launcher/latest/linux-amd64-appimage/download
#ARM
curl -L -o habilis-launcher.AppImage https://dl.habilis-console.com/launcher/latest/linux-arm64-appimage/download
```


**<span style="padding-inline-start:40px;color:#1E90FF;">방법 B</span> — wget 사용**

```bash
#AMD
wget -O habilis-launcher.AppImage https://dl.habilis-console.com/launcher/latest/linux-amd64-appimage/download
#ARM
wget -O habilis-launcher.AppImage https://dl.habilis-console.com/launcher/latest/linux-arm64-appimage/download
```

**<span style="padding-inline-start:40px;color:#1E90FF;">방법 C</span> — 홈페이지 다운로드 페이지 이용**


<br />

3. 다운로드한 파일에 실행 권한을 부여합니다.

```bash
chmod +x habilis-launcher.AppImage
```
<br />

> ⚠️ **주의**
> - `chmod +x` 명령은 AppImage 파일이 위치한 디렉토리에서 실행해야 합니다.
> - 또는 파일 탐색기에서 해당 파일을 마우스 오른쪽 클릭 → **속성** → **권한** 탭 → <strong>"프로그램으로 실행 허용"</strong>을 체크하여 동일하게 설정할 수 있습니다.

<br />

## Step 2. 하빌리스 런처 실행

아래 명령어를 실행하여 런처를 시작합니다.

```bash
./habilis-launcher.AppImage
```

정상적으로 실행되면 하빌리스 런처가 시작됩니다.
